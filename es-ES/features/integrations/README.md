# Integrations

Integrations is how you get other applications to work together with Anytype. To do this, you can use the Local API, MCP Server, or the CLI tool if you're comfortable. 

You can learn more at the [Anytype Developer Portal](https://developers.anytype.io/). 

* [Local API](local-api.md)
* [MCP Server](https://developers.anytype.io/docs/examples/featured/mcp)
* [Anytype Agents' Skill](anytype-agents-skill.md)
